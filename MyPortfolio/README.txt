MY PORTFOLIO WEBSITE - START HERE

1. Extract this ZIP file.
2. Open the extracted MyPortfolio folder in VS Code:
   File > Open Folder > MyPortfolio
3. Open index.html.
4. To preview, double-click index.html in File Explorer, or use the Live Server extension in VS Code.
5. Replace every [Your Name] and other [bracketed placeholder] with your own correct information.
6. Replace the sample email address in contact.html with a professional email address.
7. Update education, skills, projects and achievements. Do not claim skills or certificates you do not have.
8. Keep all five HTML files, the css folder and the js folder together.

PAGES INCLUDED
- index.html: Home
- about.html: About Me
- education.html: Education and Skills
- projects.html: Projects and Achievements
- contact.html: Contact

This is a starter template. Review and personalize all content before submitting it to your college.
